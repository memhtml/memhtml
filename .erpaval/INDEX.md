## architecture-patterns
- [one-surface-per-producer-prefixes-the-base](solutions/architecture-patterns/one-surface-per-producer-prefixes-the-base.md) — HTML and the raw .md routes are built from different inputs, so a base prefix is correct on whichever surface its producer touched; `${base}/` is `//` at the root and `base.length + 1` eats a character; serve at an origin root and the bug class stops existing.
- [sandbox-egress-is-set-by-the-constructor](solutions/architecture-patterns/sandbox-egress-is-set-by-the-constructor.md) — just-bash registers curl/wget ONLY when a network option is passed, so egress belongs to whoever calls `new Bash()`: eve hardcodes full access (IMDSv2 token + instance-role name reachable), a caller that omits it gets curl unregistered and the guest's fetch refused on call; `typeof fetch` is a function under both, so the capability check enforces nothing. Also: just-bash's CJS build has a broken js-exec, and js-exec is not re-entrant.
- [put-the-qualifier-in-the-claim](solutions/architecture-patterns/put-the-qualifier-in-the-claim.md) — "the index's lock is exclusive" kept its mechanism and lost the WRITABLE qualifier that carried the meaning, and got re-derived wrongly twice; write the claim so it survives as the only sentence left, then gate it with a test that fails when the qualifier is deleted.
- [one-diagram-source-two-renderers](solutions/architecture-patterns/one-diagram-source-two-renderers.md) — one `.d2` per figure drives the site's SVG and the README's committed ASCII, gated by a vitest `--check`; D2 0.7.1 probed: `fill-pattern: none` emits an unterminated CDATA, themes 300/301 texture every container with a `#0A0F25` dots-overlay no fill displaces, theme 301 is cool-tinted not achromatic (fix with `theme-overrides`), the ASCII renderer ignores `--layout` and draws diamonds in asterisks; axe passes `alt="Diagram"` and ignores inline `<svg>` without `role="img"`; a 30em measure makes natural figure width the label scale.
- [where-a-filesystem-first-agent-gets-built](solutions/architecture-patterns/where-a-filesystem-first-agent-gets-built.md) — nitro externalizes anything it resolves inside `node_modules`, so building eve's agent in an installed package gives `eve build` exit 0 and `eve start` exit 13 on an unsettled top-level await (17.3 kB entry + traced chunk vs 317 kB inlined); copy `agent/` AND `src/` at their original depth to `~/.cache/memhtml/eve/<version>/` and build there, link what the tree IMPORTS via an ancestor node_modules walk (an `exports` map can refuse `<name>/package.json`), spawn through `process.execPath`, and refuse a prebuilt `.output/` because it traces platform-native binaries. Reaching the phase at all needs a transcript over 8 KB backdated past the one-hour quiet window — fresh fixtures report `batch: 0`, which reads like coverage.
- [git-as-the-memory-plane](solutions/architecture-patterns/git-as-the-memory-plane.md) — disposability test decides file-vs-DB; R100 impossible with head stamps; merge=ours needs the driver config; mtimeMs float vs text; a parent must not open the DB its child serves; upstream debts (predecessor merge guard, negation guard, parse5 pre-newline).

## build-errors
- [the-published-artifact-is-not-the-workspace](solutions/build-errors/the-published-artifact-is-not-the-workspace.md) — every tier resolves `@memhtml/*` through pnpm's links where assets exist undeclared, so only installing the tarball can see a packaging defect: `guest/corpus.mjs` and the consolidator's `src/` were absent from every pack, and a glob copy later nested the migrations one level deep (`no such table: files`).
