# Security policy

## Supported versions

The latest minor release line of `memhtml` receives security fixes. For example, while the latest release is 0.16.2, the supported line is 0.16.x. Older minor release lines receive no fixes; upgrade to the latest release before reporting a vulnerability that has already been fixed.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/memhtml/memhtml/security/advisories/new). Include the affected version, steps to reproduce, the impact, and a minimal example when possible. Keep vulnerability details out of public issues and pull requests until coordinated disclosure.

We acknowledge reports within 7 days. Within 90 days of the report, we provide a fix or publish a security advisory describing the vulnerability and any available mitigation. We coordinate disclosure with the reporter through the private advisory and publish the advisory when the fix or mitigation is ready.
