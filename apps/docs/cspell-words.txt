# The vocabulary this project writes in, and nothing else. A word belongs here when it is a
# term of art, an identifier quoted from source, or a dependency's name — never because a
# spelling was inconvenient to fix. British spellings are not in this list: `cspell.json`
# enables the `en-GB` dictionary, so `behaviour` and `neighbour` are correct rather than
# excused.
#
# cspell splits on case and on `-`/`_`/`.`, so a compound like `rrfWeight` needs only `rrf`.
