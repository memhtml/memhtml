---
title: memhtml
description: Memory for agents, in HTML.
---

memhtml is an agent's long-term memory store: a git repository of semantic HTML files, one fact per
file, with a rebuildable SQLite index, four-arm retrieval, and a nightly curation pipeline.

The git tree is the system of record. The index is a projection, and deleting it costs nothing but
the time to rebuild.
